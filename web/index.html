MLMP live planner

The same C++ planner the CLI runs, compiled to WebAssembly and solving in a worker. Edit the obstacles, pick a planner, and watch the bundle-space trees grow: colour is tree membership, opacity is bundle level, each dot is one robot's chain tip at that vertex's bundle level, and the solution is drawn in green as each robot's tip trajectory between its start and goal arms. Switch the view to vertices only or path only when the edge web hides the result.

Traced in-browser run — frame capture copies the planner graph, so these timings and counters are not benchmark numbers.

Drag an obstacle to move it, click points with “Add obstacle” on and press Enter (or double-click) to close a new one, Delete to remove the selected one. Every edit re-solves; only the newest edit is queued.
