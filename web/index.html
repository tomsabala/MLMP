MLMP live planner

The same C++ planner the CLI runs, compiled to WebAssembly and solving in a worker. Edit the obstacles, pick a planner, and watch the bundle-space trees grow; when a run solves, the arms play the solution, interpolated in joint space exactly as the planner's motion validator checked it. Every dot is one robot's chain tip at that vertex's bundle level, and a level-L vertex owns only its first L+1 links — so read the search one level at a time.

The second canvas is the real configuration space of this scene's 2-D bundle level: each axis is one joint angle over [−π, π], grey is where the arms collide, and the tree is drawn in the space the planner searches rather than projected into the workspace.

Traced in-browser run — frame capture copies the planner graph, so these timings and counters are not benchmark numbers.

Drag an obstacle to move it, click points with “Add obstacle” on and press Enter (or double-click) to close a new one, Delete to remove the selected one. Every edit re-solves; only the newest edit is queued.
