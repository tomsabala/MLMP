MLMP trace player

Committed mlmp.traceviz/1 fixtures packed from mlmp.trace/1 recordings — seed 42, 10 s budget, 50 ms per frame. Colour is tree membership, opacity is bundle level, and each dot is one robot's chain tip at that vertex's bundle level (a level-L vertex owns only its first L+1 links). The run's solution is drawn in green as each robot's tip trajectory between its start and goal arms. Switch the view to vertices only or path only when the edge web hides the result.
